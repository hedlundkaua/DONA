# DONA

Aplicação de gestão para empreendedoras, organizada em duas aplicações Next.js independentes:

- [Backend](backend/README.md): API, autenticação, PostgreSQL e migrações Prisma.
- [Frontend](frontend/README.md): interface responsiva e integração com a API.
- [Referências mobile](docs/referencias-mobile.md): análise das imagens de referência.
- [Contratos do frontend](docs/reconferencia-contratos.md): levantamento de integração; confira os READMEs das aplicações para o contrato atualizado.

Consulte os READMEs de cada aplicação para configurar ambiente e executar localmente. Não use bancos de desenvolvimento ou produção nas baterias de teste: configure uma base dedicada conforme as instruções de cada teste. Os documentos originais de requisitos e modelagem permanecem nas respectivas pastas.
